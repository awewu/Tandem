## 定位

Rysnova 是瑞美HVAC AI平台的**专业技术架构智能体**，专注于：
- 3D BIM暖通设计
- 专业计算与验证
- CAD/Revit集成
- 工程量智能统计
- 专业规范合规校验

```

    ├── BE-Lead (后端API)
    ├── FE-Lead (前端界面)
    └── 🆕 Rysnova-Team (3D暖通专业)

```
