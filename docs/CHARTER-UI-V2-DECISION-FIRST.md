# CHARTER · UI 设计铁律 V2 — 决策导向 (Decision-First)

> **立项**: 2026-07-25 PT (P4 · 因"报表/预警只堆数据、缺使用者体验进化"立)
> **地位**: 与 `CHARTER-UI-V1` 并列。V1 管**视觉令牌**(颜色/字体/阴影/圆角)，V2 管**信息与决策体验**(结论/披露/动作)。
> **一句话**: V1 保证"好看且一致"，V2 保证"看一眼就知道该干什么"。
> **配套**: `CHARTER-UI-V1.md` (视觉铁律) · `docs/UI-IA.md`

---

## 0. 缘起

现状 PMS 驾驶舱/分析页把 KPI、漏斗、维度表**平铺堆砌**：数字很多，但老板/销售**看完不知道下一步做什么**。这不是视觉问题(V1 已管)，是**信息设计**问题。学习 Claude/Linear/Stripe 的共同心法：**先给结论，再给证据，最后给动作**。写此宪章防止"数据堆砌式报表"再产。

---

## 1. 不可妥协铁律 (Hard Rules)

### §2.1 结论先行 (BLUF · Bottom Line Up Front)
任何"分析型/预警型"页面，**第一屏第一个元素必须是一句人话结论**，而非图表或 KPI 网格。

- 结论 = "现在最重要的一件事" + "一个量化事实"。
- 例：`⚠ 3 个严重问题待处理，最紧急：投标已逾期 2 天未提交（¥580万）`
- **禁**: 页面顶部直接上 KPI 卡网格 / 漏斗 / 表格，让用户自己总结。

### §2.2 每个问题必须带"下一步动作" (Next Best Action)
预警/异常**不允许只描述现象**，必须给出**可执行的下一步**(动词开头)，最好可点击直达。

- 例：停滞项目 → "立即安排回访推进" (→ 项目详情)；决策链缺口 → "补齐经济决策人触点"。
- 现象(是什么) + 影响(所以呢) + 动作(怎么办) 三段式，缺一不可。
- **禁**: `项目停滞 90 天` 这种只有现象、没有 so-what / 没有动作的卡片。

### §2.3 渐进披露 (Progressive Disclosure)
默认只显示**决策所需的最小信息**，细节(维度明细表、全量漏斗、原始数据)折叠在"展开/详情"之后。

- 第一屏: 结论 + 待办问题 + 核心 KPI(≤4)。
- 二级(需点开): 维度分析、完整漏斗、分布表。
- **禁**: 首屏一次性渲染 5+ 个数据密集卡片。

### §2.4 优先级即视觉层级 (Priority = Visual Weight)
最重要的信息占最大视觉量。management-by-exception：**问题**比"一切正常的 KPI"更靠上、更醒目。

- 严重(critical) > 警告(warning) > 提示(info)，排序与配色(danger/warning/neutral)一致。
- 无问题时用**明确的正向空态**("一切正常")，不要留空白或假装有事。

### §2.5 数据诚实 (Data Honesty)
AI 生成 vs 规则基线 vs 真实聚合，**必须可区分**；预警的可信度**必须可度量**(接 P0 评估台)。

- AI 结论标注来源(`AI 增强` / `规则基线`)。
- 报表"准不准"用评估台通过率呈现，不靠口头保证。
- **禁**: 把降级规则输出伪装成 AI 洞察。

### §2.6 完整状态四件套 (Loading / Empty / Error / Success)
每个数据视图必须显式处理四态，且**空态与错误态也要给下一步**。

- Loading: 骨架或 spinner，不闪烁。
- Empty: 一句话解释 + 一个引导动作("创建第一个商机")。
- Error: 人话错误 + "重试"。
- **禁**: 数据为空时渲染 `0` / 空表格 / undefined。

## 2. 学习对象 (决策体验维度)

| 标杆 | 学什么 |
|---|---|
| **Claude / ChatGPT** | 结论先行、要点分层、"所以你应该…"式行动建议 |
| **Linear** | 收件箱式待办、优先级排序、键盘直达动作 |
| **Stripe Dashboard** | 财务级结论横幅(今日净额↑X%) + 可下钻明细 |
| **Superhuman** | "最重要的一封"、单一焦点、渐进披露 |

---

## 3. PR 自检清单 (强制)

提交任何"分析/预警/驾驶舱/看板"类 UI 前，逐条勾选：

- [ ] **结论先行**: 首屏第一元素是一句人话结论(BLUF)，不是图表网格
- [ ] **下一步动作**: 每条预警都有动词开头的 next action(最好可点击)
- [ ] **渐进披露**: 明细/维度表折叠，首屏 ≤4 核心 KPI
- [ ] **优先级层级**: 问题在正常 KPI 之上，严重度排序+配色一致
- [ ] **数据诚实**: AI/规则/真值来源可辨；可信度可度量
- [ ] **四态齐全**: loading/empty/error/success 都处理，空/错态带引导动作
- [ ] (并遵守 V1 全部视觉铁律)
