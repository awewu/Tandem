# W-BIM · 上线阻塞项清单（2026-07-06）

> 以下四项无法通过代码骨架继续推进，必须依赖外部输入、算法采购或专用环境，当前状态为 **阻塞**。

## 阻塞项

### 1. 4.2 · 自动盘管/布管/选型算法
- **状态**：阻塞
- **原因**：当前 `AiDesignService.propose` 为规则占位输出，无法自动完成辐射采暖盘管、风管/水管自动布线、设备选型定位。
- **所需外部输入**：
  - LoopCAD 自动盘管算法文献或逆向工程输出
  - LATS 风管自动变径/阻力计算文献
  - 或采购 HVAC 自动布局算法 SDK
- **验收**：首方案 ≤5 分钟且符合国标/ASHRAE 基线
- **建议 Owner**：算法团队 + 外部 HVAC 顾问

### 2. 2.3 · Legacy 产物迁移（A→B）
- **状态**：阻塞
- **原因**：迁移脚本 `scripts/migrate-legacy-artifacts.ts` 已创建，但无法确认 A 端（legacy 156KB 系统）数据源、schema、文件位置。
- **所需外部输入**：
  - A 端数据库/文件系统只读访问凭证
  - A 端产物表结构文档
  - 产物与报价单/合同的映射关系
- **验收**：迁移后对象存储 evidence 链完整，B 端可读取所有历史产物
- **建议 Owner**：运维/DBA + 原 A 端维护团队

### 3. 3.5 · PDF 工程图导出
- **状态**：已解堵（骨架实现）
- **实现**：
  - 后端 `DesignService.exportBomPdf` 使用 `pdf-lib` 生成 PDF，含图签、户型统计、BOM 表、价格带。
  - 新增端点 `GET /api/design/projects/:projectId/export-pdf` 返回 `application/pdf`。
  - 前端 `/bom` 页面“导出 PDF”按钮直接下载后端生成的 PDF。
- **剩余增强**：
  - 替换图签模板为公司 logo、签字栏、日期版本（需设计/交付团队提供样式）。
  - 将 SVG 工程图真正光栅化/矢量化嵌入 PDF（当前为文本摘要）。
- **验收**：`/bom` 页面点击导出可下载符合交付标准的 PDF
- **建议 Owner**：前端 + 设计/交付团队

### 4. 5.1 · Revit C# 插件按新命名空间重新编译
- **状态**：阻塞
- **原因**：后端已统一 `/api/rysnova-bim/cloud/*`，但 Revit 插件 C# 代码仍使用旧路径，需修改并重新编译打包。
- **所需外部输入**：
  - Windows + Revit 2022/2023/2024 SDK 编译环境
  - 旧 C# 代码仓库访问权限
  - 新 Revit 版本目标确认
- **验收**：Revit 插件能成功调用 clash/ifc/boq 新端点
- **建议 Owner**：C# 插件团队

## 结论

冲刺 1-5 的代码骨架、API、前端、文档、角色阶梯、审计链、价格带已闭环。上线前必须解决以上 4 项阻塞项，否则：
- AI 方案生成不可用（4.2）
- 历史产物无法迁移（2.3）
- 无法出 PDF 工程图（3.5）
- Revit 插件无法接入新平台（5.1）
