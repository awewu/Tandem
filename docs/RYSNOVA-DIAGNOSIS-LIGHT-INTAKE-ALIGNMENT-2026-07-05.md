## 0. 一句话定位

问诊 = **一条"信任 → 定金"的消费者转化漏斗**：会听会问地摸清需求，用案例与原理图建立信任，给**初步选型报价（区间）**，促成**可退定金**锁客并派单。
**精确精算、最终报价、工程出图属于后面的"手术台"（勘测 / 设计 / BIM），问诊不做精确，但可以给初步、可退、有来源的东西。**

关键区分——不是"要不要报价/图/案例"，而是**精度与承诺等级**：
- 问诊：初步选型报价（真实目录价·区间·标"以勘测为准"）＋原理示意图＋案例＋可退定金。
- 后面：负荷精算＋精确 BOM＋最终报价＋工程图纸＋正式合同。

旧引擎的病不是"有报价/图"，而是**数字是无来源的硬编码魔数**（面积×1680、节能40%、匹配度98%、增值5-10%）。诚实红线：报价必须来自真实产品目录价，图必须标"示意"，定金必须可退。

依据用户裁定 + 你自己 2026-06-06 的 C 端 UI/VI 架构确认稿（主线：家庭感受→房屋条件→系统需求→方案解释→预算与长期价值→专业深化；结果页含三档方案、预算/月供、原理图/2D/3D、设备品牌配置、下一步）。

## 1. 问诊要做什么 / 不做什么（请打勾确认）

**问诊要做（建信任 → 促定金）**
- [ ] 听懂业主用生活语言说的困扰（不逼填专业标签）
- [ ] 渐进追问，发现业主没意识到的隐性痛点（像医生看诊）
- [ ] 归纳出「需求共识画像」：痛点方向 + 期待
- [ ] 给三档建议（essential / balanced / premium）+ 适合人群
- [ ] **展示同城/同户型案例演示 + 效果对比（before/after、业主证言）建立信任**
- [ ] **配套系统组合的原理示意图（讲清怎么连、解决什么）**
- [ ] **初步选型报价：真实产品目录价驱动，给区间，标注"初步预估·以现场勘测为准"**
- [ ] **促成可退定金支付，支付即建单并派给就近经销商**
- [ ] 生成初步咨询报告、可分享

**问诊不做（留给后面套件）**
- [ ] 不算精确负荷 / 精确选型 / 最终报价
- [ ] 不出"假精确"数字（节能率%、精确月供/ROI、匹配度%、增值%）
- [ ] 不出工程图纸、不做工程校验签字
- [ ] 不暴露设计师工作台 / BIM / 后台入口到 C 端主导航

## 3. "AI"在问诊里到底是什么（去掉炫技）

- 不是聊天机器人炫技，不是后台工具演示。
- 它是**顾问的嘴 + 脑**：会听人话、按你的 48 项痛点提纲渐进追问、发现隐性痛点、把结果归纳成结构化的需求共识画像。
- 领域知识（48 项痛点 + 规则）是**你自己的**，不依赖开源；LLM 只负责"听懂和归纳"。

## 6. 不变的硬边界

- 生产零风险：只在"新店"做，旧店照常营业。

- 隐私授权闸 + 同意留痕（PIPL / G1）保持，问诊入口前置。
- 数据归属 rysnova 产品域；Rhautt 官网只做入口与背书。
