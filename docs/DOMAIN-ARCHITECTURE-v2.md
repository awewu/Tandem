## 🤖 AI 拓客

**定位：AI 主动发现潜在客户，推送给业务员触达。不是等线索来，是 AI 帮你出去找。**

### 需求信号源

| 信号源 | AI 怎么识别 |
|--------|------------|
| 新楼盘交付 | 爬取房产网/住建局公示 → 交付日期+户数 |
| 社媒需求帖 | 监测"装修""地暖""中央空调"关键词 → 定位发帖人 |
| 二手房成交 | 链家/贝壳成交 → 老房翻新概率预测 |
| 装修平台 | 土巴兔/齐家网公开需求帖 |
| 天气/季节 | 寒潮预警 → 采暖需求激增窗口 |
| 竞品负面 | 竞品差评/投诉 → 可切入时机 |
| 老客生命周期 | 设备到龄/保修到期 → 换新提醒 |

### 业务员工作界面

- **今日 AI 发现** — 自动推送潜客线索（高/中/低意向分级）
- **区域热力图** — 哪个片区最近需求密度最高
- **触达建议** — AI 给出最佳触达方式/话术/时机
- **一键转线索** — 触达成功后直接进入"线索成交"域

### 与其他域的关系

- ← 📣 推广与增长：品牌曝光产生的公域关注人群可被 AI 拓客识别
- → 🎯 线索成交：触达成功的潜客进入正式线索池

## 🎯 线索成交

**定位：经销商的签单武器库。从线索进入到签合同的全链路管理与转化工具。**

### 获客入口（被动）
| 模块 | 说明 |
|------|------|
| AI 智能问诊 | 痛点采集 → 自动方案 → 留资转化 |
| 在线报价试算 | 户型/面积/需求 → 秒出估价 |
| 内容获客引擎 | 知识库/选型指南/案例库 → SEO+社媒引流 |
| 官网/表单/电话/门店 | 各渠道留资统一汇入 |

### 线索管理
| 模块 | 说明 |
|------|------|
| 线索智能评分 | 按问诊深度/预算/区域/紧迫度自动分级 |
| 线索自动分配 | 按区域/品牌/能力标签派单 |
| 线索跟进看板 | 线索池/状态/超时预警/公海回收 |
| 客户画像卡 | 问诊+浏览+沟通 → 360° 视图 |
| 跟进 SOP | 5分钟首联 → 2h升级 → 24h二次分配 → 7天回公海 |

### 成交转化工具
| 模块 | 说明 |
|------|------|
| 方案对比工具 | 多方案并排（配置/价格/能效/ROI） |
| 竞品应对话术库 | 针对竞品痛点的专业应答模板 |
| 客户异议处理 AI | 智能建议回复策略 |
| 案例匹配推荐 | 自动匹配相似户型/需求的成功案例 |
| 签约催单引擎 | 跟进节奏/优惠窗口/决策人识别 |

### 数据闭环
| 模块 | 说明 |
|------|------|
| 转化漏斗分析 | 曝光→问诊→留资→跟进→签约全链路 |
| 成交归因 | 渠道/内容/话术 → 哪个带来成交 |
| 经销商成交率排名 | 标杆复制 |

**应用：** `consumer-diagnosis` :4001 / `dealer-workbench` :4000（CRM 模块）
