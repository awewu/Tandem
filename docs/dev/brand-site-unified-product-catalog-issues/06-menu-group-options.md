# 06 - Website menu group options from brand navigation categories

## What to build

Replace free-text website menu group editing with brand-aware menu group options where known. Everhot should expose the real navigation categories from the current website menu so operators can place products into existing website sections.

## Acceptance criteria

- [ ] Website menu group editing uses a select, combobox, or equivalent option control instead of only free text.
- [ ] Everhot options include: 家用中央空调, 地暖系统, 全热新风, 热水系统, 燃气冷凝壁挂炉, 零冷水燃气热水器, 空气能热水器, 容积式燃气热水器, 电热水器, 采暖热水两联供.
- [ ] Rheem and Ruud use known local options if available, otherwise a clear fallback option set.
- [ ] Existing menu group values continue to display and can be preserved.
- [ ] The options appear in the product edit modal/drawer and any shelf metadata editor.
- [ ] Focused UI verification proves the Everhot options render.

## Blocked by

- 01 - Brand-filtered product listing for Rheem, Ruud, and Everhot.
