# 04 - Full product edit modal/drawer from brand pages

## What to build

Replace inline row expansion editing with a modal or drawer opened from a product row action. The editor must update the same product catalog record shown in the central product catalog and expose enough product fields for brand website maintenance.

## Acceptance criteria

- [ ] Clicking edit or modify opens a modal or drawer above the current page.
- [ ] Editing does not expand the product row inline.
- [ ] The editor groups fields into base information, website display, images/materials, specs, selling points/FAQ, and shelf state where the existing backend supports those values.
- [ ] Saving updates the product catalog record for shared product fields.
- [ ] Shelf state changes update brand-site assignment fields rather than duplicating product data.
- [ ] Closing, canceling, saving, loading, validation, and error states are handled.
- [ ] Focused interaction coverage verifies opening, saving, and refresh behavior.

- 01 - Brand-filtered product listing for Rheem, Ruud, and Everhot.
