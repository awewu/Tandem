# 03 - Responsive no-horizontal-scroll brand product table

## What to build

Redesign the brand product list table so normal desktop workbench widths do not show a horizontal scrollbar. Keep the table scannable and workbench-like, with dense product details moved into the edit modal or compact secondary text.

## Acceptance criteria

- [ ] The normal desktop brand product page has no visible bottom horizontal scrollbar.
- [ ] The table uses compact high-signal columns: product identity, category/menu, image readiness, website shelf state, order signal, and actions.
- [ ] Long product names, slugs, categories, and SKU values wrap or truncate cleanly without overlapping other UI.
- [ ] The design follows the current Rhautt Nexus / Rheem VI and existing admin component style.
- [ ] The solution does not introduce a marketing-style layout or unrelated visual system.
- [ ] A screenshot or browser check verifies the normal-width layout.

## Blocked by

- 01 - Brand-filtered product listing for Rheem, Ruud, and Everhot.
