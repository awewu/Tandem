# 5000 营销系统控制台 UI 重做 PRD

目标应用：`apps/dealer-workbench`，本地端口 `http://localhost:5000/`

参考风格：`docs/dev/hermes-tandem-vi-ui-design-audit.md`

创建时间：2026-07-24

## 0. 已确认决策

1. 5000 不再定位为完整经销商经营台，而是营销系统控制台。
2. 5000 全局主色调切换为 Rheem Red `#E4002B`。
3. 当前只保留营销系统相关能力：品牌官网、市场营销、产品、营销权限/账号，以及营销控制台必要的首页/总览。
4. 产品模块必须保留，属于营销系统核心能力之一。
5. 以下模块从 5000 中删除，不再进入本 PRD 的 UI 重做范围：`CRM 客户`、`项目`、`设计`、`BIM`、`财务`、`团队`、`售后`、`Hub`。
6. “删除”不仅表示从导航隐藏，还包括删除对应页面目录/路由文件、导航配置、首页/快捷入口、移动端入口，以及不再被保留营销模块引用的相关组件和数据文件。删除后必须通过 build 证明没有残留引用。
7. 保留范围内的现有功能不能缺失。每个保留页面 UI 重做前必须列出现有入口、按钮、筛选、表单、上传、发布、分页、导入导出、跳转、权限态；重做后逐项回归。

## 1. 背景

`apps/dealer-workbench` 目前包含大量历史经营台模块，例如 CRM、项目、设计、BIM、财务、团队、售后和 Hub。根据最新产品方向，5000 不再承载这些经营、交付、工程和财务协作场景，而是收缩为营销系统控制台。

Hermes Tandem 项目提供了一套适合企业后台的视觉语言：Apple HIG 节奏、Teams 式 AppRail、Vercel/Linear 式轻量面板、lucide 线性图标、清晰的 loading/empty/error 状态，以及 token 化颜色和字号体系。本 PRD 的目标是把 5000 改造成聚焦营销系统的控制台，并用 Rheem Red 建立统一视觉。

## 2. 产品目标

- 5000 首屏和导航只呈现营销系统相关能力。
- 品牌官网、市场营销、产品、账号/权限形成清晰的信息架构。
- 删除 CRM、项目、设计、BIM、财务、团队、售后、Hub 的页面代码和可见入口，避免用户误以为 5000 仍是完整经营台。
- 保留营销系统相关页面的现有业务能力，不因 UI 重做丢失筛选、分页、上传、发布、上架、导入导出或权限功能。
- 所有保留页面使用统一的 Rheem Red 设计系统、图标、状态、表格和空态。

## 3. 非目标

- 不重做 CRM、项目、设计、BIM、财务、团队、售后、Hub 页面。
- 不迁移或重构后端 API。
- 不改变数据库结构。
- 不新增云端图片上传能力。
- 不改变品牌站产品目录分页、上架、下架等业务规则。
- 不新增 Rheem/Ruud 官网 runtime loader。
- 不引入新的大体量 UI 框架。

## 6. 设计系统要求

### 6.1 色彩

- `brand-*`：5000 全局主 UI accent，统一使用 Rheem Red `#E4002B` 及其浅色/深色梯度。
- `surface-*`：白色、暖灰、浅灰工作面。
- `ink-*`：主文字、副文字、弱文字。
- `semantic-*`：成功、警告、错误、信息。

要求：

- 主操作按钮、导航 active、焦点环、重要链接、关键进度条使用 `brand-500`。
- 错误、删除、禁用不得使用品牌色混淆，必须使用语义色。
- Rheem/Ruud/Everhot 的具体品牌识别可作为局部标签或站点标识，但 5000 控制台全局 UI accent 固定为 Rheem Red。
- 不允许业务页面散落大量 raw hex、`red-500`、`slate-500` 等硬编码色。

### 6.2 字体

建议字体栈：

```css
'Noto Sans SC',
'Inter',
-apple-system,
BlinkMacSystemFont,
'Segoe UI Variable Text',
'Segoe UI',
'PingFang SC',
'Microsoft YaHei UI',
'Microsoft YaHei',
system-ui,
sans-serif
```

后台页面不得滥用超大标题；表格页标题建议 20-24px。

### 6.3 图标

- 统一使用 `lucide-react`。
- AppRail 图标：18px。
- 顶部/移动导航图标：20-22px。
- 表格行操作、筛选按钮、普通按钮图标：16px。
- 同一级导航不得混用 emoji、彩色插画、filled icon。

## 7. 关键 UI 模式

### 7.1 Shell

5000 shell 应聚焦营销系统：

- 左侧 AppRail 只保留：品牌官网、市场营销、产品、账号/权限。
- 顶部 Topbar 显示当前营销模块、品牌/站点上下文、用户信息。
- 二级 SubSidebar 只显示当前营销模块下的子页面。
- 已删除模块不得出现在 AppRail、SubSidebar、移动导航、快捷入口或首页卡片中。

### 7.2 表格与列表

- 顶部筛选区：搜索、状态、分类/品牌/角色、时间范围、刷新。
- 行 hover 有浅色反馈。
- 行主对象左侧突出，次信息弱化。
- 行操作尽量用图标按钮 + tooltip 或短中文命令。
- loading、empty、error 状态占据容器，不让页面塌陷。
- 普通桌面宽度下不得出现明显横向滚动条。

### 7.3 状态标签

必须统一状态组件：

- 成功：已完成、已上架、已启用、已发布。
- 信息：进行中、待处理。
- 警告：待审核、风险、即将逾期。
- 错误：失败、已下架、停用、逾期。
- 中性：未配置、未上架、草稿、无数据。

品牌站产品页特别要求：

- 网站货架状态：`未上架`、`已上架`、`已下架`。
- 产品目录启用/停用状态必须与网站货架状态视觉和语义分离。

## 8. 页面级要求

### 8.1 品牌官网管理

- 品牌站列表要能清楚区分 Rheem、Ruud、Everhot。
- 每个站点卡片/行显示：品牌、域名/本地端口、发布状态、产品数量、最近更新时间、主要动作。
- 单品牌站页面必须显示当前具体品牌上下文，避免误操作到其他品牌。
- 产品货架状态必须清楚，操作按钮与状态一致。

### 8.2 市场营销

- GEO、文案 Copilot、舆情雷达、营销自动化、物料库使用统一模块卡片。
- AI/Copilot 类能力使用 `Sparkles` 等一致图标和轻品牌色，不做炫技风格。
- 营销系统首页/总览只展示营销相关指标、待办、风险和快捷入口。

### 8.3 产品

- 产品目录、产品资料、目录底座共用同一筛选/表格样式。
- 图片、SKU、品牌、分类、目录状态、网站上架状态分层展示。
- 分页、搜索、筛选改动只刷新请求页，不做全量加载。

### 8.4 账号/权限

- 账号表格显示姓名、联系方式、角色、状态、最近登录/创建时间、操作。
- 角色标签统一。
- 启停、重置密码、退出登录等危险/敏感动作需要明确确认。
- 只保留营销系统需要的账号/权限入口，不展示经营、项目、工程、财务相关权限入口。

## 9. 验收标准

### 9.1 视觉验收

- 5000 呈现为营销系统控制台，而不是完整经营台。
- CRM、项目、设计、BIM、财务、团队、售后、Hub 对应页面/路由代码已删除，且不再出现在可见导航和首页入口。
- 保留页面主按钮、次按钮、输入框、select、状态 pill、卡片、表格样式一致。
- 所有通用图标来自 `lucide-react`。
- 中文文案无乱码、无英文残留、无测试数据痕迹。
- loading、empty、error 状态明确可见。

### 9.2 功能回归

- 保留范围内路由跳转正常。
- 登录/退出正常。
- 品牌站、产品、账号、市场营销核心操作不回退。
- 产品分页/搜索/筛选不改动已有正确行为。
- 品牌站上架/下架状态不被 UI 重做破坏。
- 图片上传等已有能力不被破坏，但本 PRD 不要求新增上传能力。
- 已删除模块不得以页面路由、导航入口、快捷入口、首页卡片形式继续暴露。
- 访问被删除模块路径时不得展示旧业务页面；应返回 Next 默认 404 或明确重定向到营销控制台入口。

### 9.3 技术验收

- `pnpm.cmd --dir apps/dealer-workbench run build` 通过。
- build 不得出现已删除模块的 import、route、type、component 残留引用错误。
- 相关 smoke 脚本按触达模块运行。
- UI 变更页面至少进行桌面和移动视口截图检查。
- 无新增大体量 UI 依赖。
- 无无关后端/数据库改动。

## 11. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 用户仍看到旧经营台模块 | 明确删除导航、快捷入口、首页卡片；截图验收 |
| 误删营销系统仍需要的功能 | 对保留页面建立功能保留清单 |
| 品牌色混乱 | Rheem Red `#E4002B` 固定为 5000 全局 UI accent |
| 表格为了好看牺牲效率 | 后台页面优先扫描效率，控制卡片化 |
| 历史路由残留导致误访问 | 删除对应页面/路由代码；访问旧路径应 404 或重定向到营销控制台入口 |
