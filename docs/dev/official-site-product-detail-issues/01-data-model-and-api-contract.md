# 01 - 官网产品详情数据模型与 API 合同

## What to build

为产品记录增加官网详情富文本字段，并让后台保存接口、后台读取接口、官网前台产品详情接口都能稳定读写该字段。详情内容必须持久化到数据库，不能只存在前端状态、静态 JSON 或内存缓存中。

优先复用现有产品目录/品牌官网产品数据结构；如果已有官网产品扩展字段或展示配置模型，应在既有模型内扩展，避免新建平行产品表。

## Acceptance criteria

- [ ] 产品数据库记录或官网产品展示扩展记录中新增 `officialDetailHtml` 或等价字段。
- [ ] 字段类型可保存较长 HTML 内容，满足长图富文本详情。
- [ ] 后台产品创建/编辑接口可以保存该字段。
- [ ] 后台产品详情/编辑读取接口可以返回该字段。
- [ ] 官网产品详情接口可以返回该字段。
- [ ] 保存后刷新页面或重新请求接口，详情内容仍从数据库返回。
- [ ] 字段命名、DTO、schema、类型定义和测试夹具保持一致。
- [ ] 不引入商城、小程序、价格、库存、下单等交易字段。

## Verification

- [ ] 运行相关产品 API/合同测试。
- [ ] 如涉及架构归属，运行 `npm run harness:arch` 或说明未运行原因。

## Blocked by

None - can start immediately.
