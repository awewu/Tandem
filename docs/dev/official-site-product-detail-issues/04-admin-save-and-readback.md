# 04 - 后台保存与数据库回显闭环

## What to build

打通后台产品详情富文本的保存、读取、回显闭环。运营保存后刷新后台页面，应能看到数据库中持久化的官网产品详情内容。

## Acceptance criteria

- [ ] 产品保存时提交官网详情富文本字段。
- [ ] 后端成功将详情内容写入数据库。
- [ ] 后台编辑已有产品时从接口读取并回显详情内容。
- [ ] 保存空内容可以清空详情字段。
- [ ] 接口错误、保存中、保存成功状态符合现有产品编辑体验。
- [ ] 不因未填写官网详情阻止产品基础信息保存。
- [ ] 旧产品没有详情字段时仍可正常打开和保存。

## Verification

- [ ] 手动或自动验证“填写详情 -> 保存 -> 刷新 -> 回显”。
- [ ] 运行相关产品保存测试或前端表单测试。

## Blocked by

- 01 - 官网产品详情数据模型与 API 合同。
- 02 - 后台官网产品详情富文本编辑器。
