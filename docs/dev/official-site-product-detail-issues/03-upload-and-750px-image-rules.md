# 03 - 详情图上传与 750px 展示规则

## What to build

复用现有上传能力，让富文本中的详情图片按官网详情规则展示：推荐宽度 750px，高度不限，保持原始比例，多图按内容顺序向下排列。

## Acceptance criteria

- [ ] 富文本插入图片时复用现有上传接口或现有资产上传组件。
- [ ] 上传格式限制沿用当前系统能力，至少明确 `png`、`jpg`、`jpeg`、`webp` 是否支持。
- [ ] 后台编辑器内图片预览不被拉伸变形。
- [ ] 前台详情页图片最大展示宽度为 750px。
- [ ] 移动端图片不超过屏幕宽度。
- [ ] 图片高度使用 `auto` 或等效逻辑，不限制长图高度。
- [ ] 多张图片按富文本顺序从上到下展示。
- [ ] 图片 URL 保存到数据库中的富文本内容里，不能依赖本地临时 blob 地址。

## Verification

- [ ] 用 750px 宽长图样例验证后台预览和前台展示。
- [ ] 用窄屏视口验证图片自适应不横向溢出。

## Blocked by

- 02 - 后台官网产品详情富文本编辑器。

可先并发调研现有上传组件和样式落点，但最终接入依赖编辑器。
