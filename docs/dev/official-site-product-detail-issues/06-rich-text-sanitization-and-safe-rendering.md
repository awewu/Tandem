# 06 - 富文本安全清洗与安全渲染

## What to build

为官网产品详情富文本增加保存或渲染阶段的安全约束，防止脚本注入、危险属性执行和不可信图片来源污染官网页面。

## Acceptance criteria

- [ ] 后端保存前或前端渲染前存在 HTML 白名单清洗。
- [ ] `script`、事件属性如 `onerror`、危险协议如 `javascript:` 不会执行。
- [ ] 允许的基础标签覆盖官网详情需要：段落、标题、列表、链接、表格、图片等。
- [ ] 图片 URL 来源遵循现有上传域、站内静态资源或允许的 CDN 策略。
- [ ] 安全清洗不破坏正常详情图展示。
- [ ] 前台渲染富文本时使用受控组件或明确的 sanitize 流程。

## Verification

- [ ] 增加或执行富文本安全负向用例。
- [ ] 手动验证恶意 HTML 不执行，正常图片仍展示。
