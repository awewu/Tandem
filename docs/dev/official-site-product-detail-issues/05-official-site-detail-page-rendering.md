# 05 - 官网产品详情页渲染

## What to build

官网产品列表点击某个产品后进入产品详情页，页面读取数据库中的官网详情富文本并渲染。详情主体最大宽度 750px，居中展示，长图自然向下滚动。

## Acceptance criteria

- [ ] 官网产品列表的产品点击行为能进入对应产品详情页。
- [ ] 详情页根据产品 ID 或 slug 请求产品详情数据。
- [ ] 详情页展示产品基础信息，沿用现有官网样式。
- [ ] 详情页展示 `officialDetailHtml` 或等价字段内容。
- [ ] 富文本容器最大宽度 750px，并水平居中。
- [ ] 长图高度不限，页面自然纵向滚动。
- [ ] 移动端不出现由详情图导致的横向滚动。
- [ ] 无详情内容时不报错，展示基础信息和合理空态。
- [ ] 页面文案和命名保持“官网产品详情”，不出现商城交易语义。

## Verification

- [ ] 用至少一个有详情内容的产品验证前台渲染。
- [ ] 用至少一个无详情内容的产品验证空态。
- [ ] 运行相关官网前端构建或 smoke。

## Blocked by

- 01 - 官网产品详情数据模型与 API 合同，需要接口字段。

可先并发做前台路由/页面骨架和静态样式，接口联调等 01 完成。
