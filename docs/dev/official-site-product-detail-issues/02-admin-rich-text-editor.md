# 02 - 后台官网产品详情富文本编辑器

## What to build

在产品新增/编辑页增加“官网产品详情”富文本编辑区域。运营可以在该区域插入详情图片，也可以编辑基础文字、标题、列表、链接、表格或参数说明。

该区域只表达官网产品详情，不应写成商城商品详情。

## Acceptance criteria

- [ ] 产品新增/编辑页出现“官网产品详情”字段区域。
- [ ] 使用富文本框形式维护内容，而不是普通 textarea。
- [ ] 支持插入图片，并能在编辑器内预览。
- [ ] 支持基础图文排版能力：段落、标题、加粗、列表、链接、表格或等价参数说明。
- [ ] 编辑器提示推荐上传 750px 宽详情图，高度不限。
- [ ] 富文本内容变化能进入产品保存 payload。
- [ ] 重新打开已有产品时，能回显已保存的详情内容。
- [ ] UI 风格符合现有 Rhautt Nexus / Rheem VI，不做营销页式大卡片布局。

## Verification

- [ ] 运行相关前端单测、组件测试或构建。
- [ ] 如果该模块有现有表单保存 smoke，补充或更新覆盖。

## Blocked by

- 01 - 官网产品详情数据模型与 API 合同，需要最终字段名和接口合同。

可先并发做 UI 骨架，但保存联调必须等 01 字段合同确定。
