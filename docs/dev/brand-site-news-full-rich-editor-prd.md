# PRD：品牌官网资讯完整富文本编辑器

## 1. 背景

品牌官网资讯后台当前已经从基础正文框逐步扩展到富文本能力，但现阶段能力仍偏“官网资讯专用编辑器”：系统预设正文、导语、小标题、引用、图片尺寸和对齐等结构，限制较多。

用户新的产品判断是：资讯正文编辑器应直接对齐常见 CMS / 富文本编辑器工具栏能力。排版自由度交给运营人员控制，系统只负责提供完整编辑能力、安全白名单、保存、预览和官网展示一致。

因此，本 PRD 将目标从“受限新闻稿编辑器”调整为“完整富文本编辑器 + 安全白名单 + 官网默认 VI 样式兜底”。

## 2. 目标

- 后台正文编辑器能力对齐常见 CMS 富文本工具栏。
- 运营可以自主控制文字格式、段落样式、字号、颜色、对齐、缩进、链接、图片和媒体。
- 保存后的正文在后台预览和官网详情页中保持一致。
- 系统保留安全清洗规则，禁止危险 HTML、脚本和不安全链接。
- 默认内容不做特殊设置时，仍符合 Rhautt / Everhot 官网 VI 和新闻稿排版质感。

## 3. 用户目标

作为官网运营人员，我希望后台资讯正文编辑器具备接近常见富文本编辑器的完整能力，这样我可以自由排版新闻稿、活动稿、产品动态和公告，而不需要每次让开发改样式。

作为系统管理员，我希望运营可以自由排版，但不能提交危险脚本、不安全链接或破坏官网基础结构的内容。

作为网站访客，我希望看到的资讯正文排版清晰、正式、稳定，不因为后台编辑自由度提高而出现错乱或安全问题。

## 4. 范围

### 4.1 本期范围

实现一个完整富文本编辑器工具栏，能力包括：

- 加粗
- 斜体
- 下划线
- 删除线
- 引用
- 行内代码或代码样式
- 项目列表
- 编号列表
- 减少缩进
- 增加缩进
- 字号选择
- 段落/文本样式选择
- 文字颜色
- 背景色
- 左对齐
- 居中
- 右对齐
- 两端对齐
- 清除格式
- 链接
- 图片上传/插入
- 图片尺寸
- 图片对齐
- 图片图注
- 图片替换
- 图片删除
- 媒体/视频入口预留

### 4.2 暂不做

- 多人协同编辑。
- 版本历史。
- 定时发布。
- 拖拽式页面搭建。
- 复杂表格编辑。
- Markdown / HTML 源码双模式。
- AI 自动排版。

## 5. 功能需求

### 5.1 工具栏能力

工具栏应接近常见 CMS 富文本工具栏，而不是仅提供少数新闻稿预设。

建议工具栏分组：

1. 文字格式
   - 加粗
   - 斜体
   - 下划线
   - 删除线
   - 清除格式

2. 段落结构
   - 正文
   - 标题
   - 小标题
   - 引用
   - 代码样式

3. 列表和缩进
   - 项目列表
   - 编号列表
   - 减少缩进
   - 增加缩进

4. 字体呈现
   - 字号
   - 文字颜色
   - 背景色

5. 对齐
   - 左对齐
   - 居中
   - 右对齐
   - 两端对齐

6. 内容插入
   - 链接
   - 图片
   - 视频/媒体入口预留

### 5.2 选中状态

工具栏必须有清晰选中态：

- 光标位于加粗文字内时，加粗按钮高亮。
- 光标位于斜体、下划线、删除线文字内时，对应按钮高亮。
- 光标位于列表内时，对应列表按钮高亮。
- 光标位于标题、引用、正文段落时，对应段落样式高亮。
- 光标位于链接内时，链接按钮高亮。
- 选中图片时，图片尺寸、对齐、图注、替换、删除控件可用。
- 未选中图片时，图片专属控件置灰。

### 5.3 编辑体验

编辑器必须稳定：

- 光标不能回弹到正文开头。
- 点击工具栏不能造成编辑区整体刷新感。
- 保存前必须读取编辑器当前最新 DOM，而不是依赖延迟同步状态。
- 粘贴内容时应清洗无关样式。
- 从 Word、微信、网页复制内容时，应尽量保留段落和列表结构。
- 不允许粘贴内容带入危险脚本和事件属性。

### 5.4 图片能力

正文图片必须支持：

- 上传 PNG/JPG。
- 插入到当前光标位置。
- 替换当前选中图片。
- 删除当前选中图片。
- 设置尺寸。
- 设置左/中/右对齐。
- 设置图注。

推荐 HTML 结构：

```html
<figure data-size="large" data-align="center">
  <img src="/api/v2/file-artifact/{id}/content" alt="图片说明" loading="lazy">
  <figcaption>图片图注</figcaption>
</figure>
```

尺寸值：

- `small`
- `medium`
- `large`
- `full`

对齐值：

- `left`
- `center`
- `right`

### 5.5 链接能力

链接必须支持：

- 对选中文字加链接。
- 未选中文字时插入链接文本。
- 支持站内相对路径。
- 支持 `https://`、`mailto:`、`tel:`。
- 外链自动添加 `target="_blank"` 和 `rel="noopener noreferrer"`。
- 禁止 `javascript:` 和其它危险协议。

### 5.6 字号和颜色

运营可以控制字号和颜色，但系统应限制在白名单内。

建议字号白名单：

- `12px`
- `14px`
- `16px`
- `18px`
- `20px`
- `24px`
- `28px`

建议颜色白名单：

- 官网默认正文色
- 官网标题色
- Rheem / Everhot 品牌红
- 中性灰
- 提示/强调色

不建议允许任意 HEX 输入作为第一期默认能力。若必须允许，保存前仍需要安全清洗和视觉审计。

### 5.7 默认 VI 兜底

如果运营不手动设置样式，正文应自动呈现为正式新闻稿效果：

- 正文字号、行高、段距统一。
- 标题层级清晰。
- 列表间距自然。
- 引用有明显视觉区分。
- 图片和图注符合官网样式。

即：编辑器给运营自由度，但默认样式仍保持官网 VI。

## 6. 数据与安全

### 6.1 存储方式

本期继续保存为受限 HTML。

原因：

- 当前 `site_news_articles.body` 已是正文字段。
- 官网前端消费简单。
- 能最快支持运营自由排版。

### 6.2 HTML 白名单

允许标签：

- `p`
- `br`
- `strong`
- `b`
- `em`
- `i`
- `u`
- `s`
- `ul`
- `ol`
- `li`
- `a`
- `h2`
- `h3`
- `blockquote`
- `code`
- `span`
- `figure`
- `figcaption`
- `img`

按需评估：

- `video`
- `source`
- `iframe`

`iframe` 默认不允许，除非后续明确视频平台白名单。

### 6.3 属性白名单

允许属性：

- `a.href`
- `a.target`
- `a.rel`
- `img.src`
- `img.alt`
- `img.loading`
- `figure.data-size`
- `figure.data-align`
- `span.data-size`
- `span.data-color`
- `span.data-bg`
- `p.data-align`
- `h2.data-align`
- `h3.data-align`
- `blockquote.data-align`

禁止：

- inline event handler，例如 `onclick`
- `script`
- 任意 `style` 第一阶段默认不放开
- `javascript:` URL
- 未授权 iframe

### 6.4 CSS 映射

为避免任意 style 污染官网，推荐保存语义属性而非 style：

- `data-size="14|16|18|20|24"`
- `data-color="brand|ink|gray|muted"`
- `data-bg="none|soft|brand-soft"`
- `data-align="left|center|right|justify"`

官网和后台预览用 CSS 统一映射这些属性。

## 7. 官网详情页要求

本阶段官网详情页不要求完整仿瑞美新闻详情页模板。

必须做：

- 正文排版效果接近正式新闻稿。
- 后台编辑区、后台详情预览、官网详情页样式一致。
- 支持正文富文本能力渲染。
- 支持上一篇 / 下一篇。

暂不强制：

- 面包屑。
- 浏览量。
- 分享入口。
- 作者/来源。
- 推荐新闻。

## 8. 后台预览要求

后台必须提供：

- 卡片预览。
- 详情预览。

详情预览必须尽量接近官网详情页正文效果，包括：

- 标题层级。
- 段落。
- 加粗/斜体/下划线/删除线。
- 列表。
- 缩进。
- 引用。
- 字号。
- 颜色。
- 对齐。
- 图片。
- 图注。

## 9. 发布校验

发布时硬校验：

- 标题必填。
- 摘要必填。
- 封面图必填。
- 正文不能为空。
- 正文 HTML 通过安全清洗。

发布时软提示：

- 摘要过长。
- 正文过短。
- 正文没有小标题。
- 图片没有图注。
- 存在过多颜色或字号变化。

## 10. 验收标准

- 工具栏能力与目标截图的主能力基本一致。
- 选中态清晰可见。
- 运营可以编辑出正式新闻稿正文效果。
- 保存后官网详情页能显示相同正文效果。
- 光标不回弹。
- 点击工具栏无明显刷新感。
- 图片可上传、替换、删除、设置尺寸、设置对齐、设置图注。
- 粘贴内容不会带入危险 HTML。
- 官网详情页支持上一篇 / 下一篇。

## 11. 实施建议

### Phase 1：编辑器工具栏补齐

- 下划线。
- 删除线。
- 清除格式。
- 缩进。
- 对齐。
- 字号。
- 颜色。
- 背景色。
- 选中态完善。

### Phase 2：数据清洗升级

- 扩展白名单。
- 使用 `data-*` 属性映射字号、颜色、对齐。
- 官网和后台共用相同 CSS 语义。

### Phase 3：官网详情导航

- 增加上一篇 / 下一篇。
- 依据发布排序或发布时间计算。

### Phase 4：运营质量提示

- 摘要长度提示。
- 正文结构提示。
- 图片图注提示。

## 12. 决策

采用“完整富文本编辑器 + 安全白名单 + 默认 VI 样式兜底”的方向。

排版自由度交给运营，但系统必须保证：

- 安全。
- 保存稳定。
- 预览一致。
- 官网默认视觉不崩。
