# Issue 06: 结构化官网内容编辑器迁移

## What to build

Migrate the structured website content editing capability from the 5012 reference into the native 5000 console. This includes specs, badges, features, highlights, certificates, FAQs, gallery links, official copy fields, and positioning taxonomy terms.

## Acceptance criteria

- [ ] Operators can edit specs as key/value rows.
- [ ] Operators can edit badges.
- [ ] Operators can edit features as title/description rows.
- [ ] Operators can edit highlights, certs, FAQs, and gallery fields where present.
- [ ] Operators can edit positioning terms from taxonomy.
- [ ] Saving structured fields preserves the expected product metadata shape.
- [ ] The editor follows current 5000 VI and avoids a raw 5012 visual clone.
