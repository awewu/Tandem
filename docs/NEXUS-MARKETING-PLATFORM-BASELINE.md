> 本文件是营销中台**新阶段的唯一权威起点**。定位、范围、十模块体系、文档索引、下一步都在这里。

## 一句话定位
**Rhautt Nexus = 面向暖通设备品牌的 AI 营销中台。** 把「产品 + 品牌」变成可测量的高意向需求。
- 🛡️ 护城河 = **产品与技术事实基座**（产品是最大竞争优势）。
- 🗡️ 差异矛头 = **AI-GEO 可见度引擎**（AI 时代的破局点，贯穿洞察/需求/度量/增长）。
- 🎯 本阶段聚焦 = **营销中台（品牌赋能 GTM + CORE 底座 + 线索飞轮）**；客户赋能已剥离为独立产品线。

## 本阶段边界（清爽）
- **在做**：品牌洞察/定位 → 品牌内容 → 需求生成(AI-GEO) → 渠道营销 → 线索获客(问诊/公域) → 度量(北极星)。
- **已剥离(独立产品线·停挂载·目录留存·可逆)**：客户赋能=报价 CPQ / 选型方案 / 交付 / 合同 / BIM / 运维 / 售后。
- **接缝留在营销中台护飞轮**：`ingress`(获客) · `diagnosis`(AI问诊) · `crm`(线索池) · `dispatch`(派单)。

## 宪章基座（锁定原则 · 不可违背）
> 以下为新增宪章级红线，任何模块/内容/AI 输出均须遵守；违背视为架构违规。

- **基座1 · 品牌 VI/SI/UI 独立，禁混淆幻觉**：Rheem / Ruud / Everhot / Lithnova 各自的 **VI(视觉)/SI(店面空间)/UI** 是**独立体系**，以各品牌官方标准为准（Rheem Red `#E4002B`、Ruud 官方件、Everhot/Lithnova 各自 token，`packages/tokens/<brand>.css`）。**不得**跨品牌套用、不得与内部工具 VI（Tandem `#C8202C`）混淆、**不得凭空生成/臆造非授权品牌视觉（防幻觉）**。护栏：`guard:rheem-vi-production:strict` · `guard:ruud-vi` + 每品牌 VI 校验；禁内联 hex。
- **基座2 · 品类营销 = 竞品分析核心**：竞争分析以**品类**为组织轴（如燃气热水器 / 空气源热泵 / 商用多联机），而非仅按品牌。竞品对标(4.12)、市场洞察(模块1)、GEO 声量份额均按**品类维度**切分。品类是连接 产品↔竞品↔市场↔内容 的主轴。
- **基座3 · 产品营销政策 ⟵ 毛利测算监控闸**：任何产品营销政策（定价/促销/返利/套餐/折扣）制定与发布，**必须实时挂接毛利测算**；毛利低于阈值须告警并阻断发布。复用并上抬 `PriceGuardrailService`（毛利护栏）到政策层。**无毛利测算的营销政策不得发布**。
- **基座4 · GEO 反"AI 套路"红线**：GEO 的市场推广与监控必须**基于真实事实 + 研究支撑 + 可验证 lift**，严禁退化为"套模板 / 刷内容 / 空泛 AI 生成"的浅层套路。硬要求：① 内容事实源自产品事实基座（产品页 JSON-LD 源自 D2，禁手写事实）；② 策略须研究支撑（`geo-strategies` 论文来源）；③ 动作须过治理闸（`geo-actions`）；④ 效果须 lift 验证（实验第7层），无 lift 不得宣称有效。
- **基座5 · 品牌涡轮地基（飞轮=架构底座，非仅指标）**：整个平台建在一台复利飞轮上——`产品事实基座 → GEO内容 → AI可见度 → 高意向线索 → 成交 → 成效数据 → 反哺事实/内容/策略 → 更强GEO…`。两支柱(事实基座🛡️ + AI-GEO🗡️) + 度量归因 + AI 是涡轮核心部件；北极星(GEO高意向线索)是其转速表。**红线(有据)**：飞轮每一环必须靠**真实归因/lift**证明在转，不得靠叙事宣称"飞轮在飞"(守基座4)。

- **基座6 · 国际竞品持续学习监控（防闭门造车 · 有牙）**：竞争格局判断**必须基于实证检索，禁凭印象断言**。固定监控四条赛道：
  - **GEO 监测型**：Profound（企业标杆·来源级引用·SOC2）· Peec AI（中端 SoV）· Otterly（入门）· AthenaHQ（来源情报）。
  - **多门店/多品牌闭环执行型（最贴近我方形态）**：**Yext**（Knowledge Graph 实体图谱「一次更新流向所有渠道」+ Scout 受治理动作）· **SOCi**（品牌训练 AI Agent + 批量动作/审批流/分级权限，1→10万+门店）· **Uberall GEO Studio**（导入→自动基线→门店级建议→一键应用→复测，**完整执行闭环**）。
  - **Agentic 营销平台**：Salesforce Agentforce/Marketing Cloud Next · HubSpot Agent Hub + AEO · Typeface。
  - **架构范式**：**Palantir Foundry Ontology**（数据+逻辑+动作+安全四重整合；objects/links 名词 × actions/functions 动词）。
  **硬要求**：① **每条结论标注检索日期与出处**，无实证不得写入战略文档（与基座4同源精神）；② **季度复核**，重大事件（收购/新品类/定价重构）即时更新——例：Scrunch 于 2026-06 被 Sitecore 收购；③ **发现既往结论有误必须显式更正并留痕**（已发生：初版"执行侧无人区"判断被 Yext/SOCi/Uberall 证伪，见 `COMPETITIVE-ANALYSIS.md` §2.1b）；④ **"我方领先"的主张必须可证伪**（绑定 lift/事实深度等证据），否则不得对外宣称；⑤ **借鉴机制、不照搬架构**——严禁引入超出我方规模的过度工程（如 Foundry 数据集成层/微服务群、图数据库）。落档固定：`docs/strategy/COMPETITIVE-ANALYSIS.md`（结论）+ `docs/strategy/PROFOUND-PARITY-BACKLOG.md`（补齐项）。

## 战略层与品牌涡轮（顶层 × 底座）
```
┌── 品牌 GTM 战略呈现层(顶层·战略)：定位 / 目标客群 / 价值主张 / 4P play / 战役主题 / 品牌 OKR ──┐
│         ↓ cascade 下达为可测 OKR            ↑ CMO / 事业部驾驶舱 呈现+闭环监控                    │
│   十大模块（执行）─────────────────────────────────────────────────────────────────────────── │
└── 品牌涡轮地基(底座·飞轮)：事实基座 × GEO × 度量 × AI 的复利闭环 ─────────────────────────────┘
```
- **GTM 战略呈现层(新·顶层)**：CMO/事业部编制并呈现 GTM 战略，向下 cascade、向上被驾驶舱监控；消费 模块1洞察+模块2 STP+模块4产品，产出可下达的战略。**红线(有牙)**：战略必须 cascade 成**可测 OKR** 并被 CMO 舱**闭环监控**，不得是漂亮 PPT/装饰仪表盘。
- **品牌涡轮地基(基座5)**：见上，飞轮做成架构底座，越转越快、可复利、可测量。
- 事业部各有一份 GTM 战略与一台品牌涡轮(按品牌/品类切，呼应基座1/2)。

## 设计 Token 体系（宪章级 · 两套分明，收敛此前混乱）
> 一句话：**内部工具 UI 对齐 Tandem 设计 token；对外品牌站守各品牌独立官方 VI。两套物理分文件、分别守门禁，禁混用。**

- **① 内部工具 UI = 对齐 Tandem 设计 token 体系**（营销中台操作台 / 品牌控制台 / 各驾驶舱 / dealer-workbench 等**内部员工工具**）：
  - 源：Tandem `app/globals.css`「Tandem Design Tokens（Apple HIG + MS Fluent + Vercel Geist）」——`--brand-50..900`(brand-500 `#C8202C` primary / 600 `#9F1822` hover)、`--radius-*`、`--shadow-*`、`--radius`(10px)。
  - 落法：营销中台在 `packages/tokens/console.css`(新) **镜像** Tandem token，`packages/ui` 共享组件消费之。**只对齐 token，不 import Tandem 代码**（守边界：对 Tandem 唯一依赖=AI 治理网关；设计同步经 governed 复制）。参照 `docs/dev/hermes-tandem-vi-ui-design-audit.md`。
- **② 对外品牌站 VI/SI = 各品牌独立官方（基座1）**：`packages/tokens/<brand>.css`——Rheem `#E4002B`、Ruud/Everhot/Lithnova 各自官方件。**禁用** Tandem 内部色 `#C8202C` 于任何对外品牌站。
- **判定规则**：UI 是"内部员工工具" → 用 Tandem token；是"对外品牌资产" → 用品牌独立 VI。门禁分别守：内部=UI 一致性；对外=`guard:rheem-vi-production:strict` / `guard:ruud-vi`。
- **纠偏**：此前 VI/token 表述散乱、路径失真（如指向不存在的 `public/css/rheem-official-tokens.css`）。本节为**唯一权威 token 口径**，冲突以此为准。

## 北极星与关键指标
- 北极星：**GEO 高意向线索数**（品牌建设→需求的可测量桥·已建分渠道归因）。副：高意向线索→成交率(接缝)。
- 品牌资产(领先)：知名度/美誉度/NPS/AI可见度(AIVS/被引/SoV)。效果(滞后)：成交率/GMV/ROI/LTV。
