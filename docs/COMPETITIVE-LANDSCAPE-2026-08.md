## 六、落地原则 (内创模型，服务快速形成价值)

1. **能借直接借** —— 行业已验证有效的形态 (每日简报/智能报价/拜访提取/进度风险) 直接学来搬到瑞美/瑞德，不因"是竞争对手"就绕开，不重复论证可行性。
2. **借来的东西套现成治理链** —— 结果交付型 Agent 上线时复用 governedChat/授权/审计/24h 否决，安全前提下尽快跑真实业务。
3. **按真实经营痛点排优先级** —— 落地顺序由瑞美/瑞德的实战痛点决定 (报价慢、OKR 风险看不见、拜访记录失真)，不由"补齐竞品功能清单"决定。
4. **可量化价值优先** —— 每个落地项要能说清"在真实业务里省了多少时间/减少多少差错/提升多少出单"，对齐行业公开的量化基准 (出单 +75% / 销售周期 -45% / 拜访规划半天→5min)。
5. **MCP/对外互通按自用价值判断** (更新 Owner 2026-06-08 取舍): 不为"当竞品网关"去做，但**若 MCP 能让自用 Agent 更快接上内部/外部工具、形成价值，就学来用** —— 判断标准是"对自用落地是否有价值"，不是"是否针对竞品"。
