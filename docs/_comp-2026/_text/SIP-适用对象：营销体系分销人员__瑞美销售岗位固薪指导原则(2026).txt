销售岗位固薪指导原则（2026）
一、 目的
为保障销售岗位固定薪资核定与发放的公平性、科学性，强化岗位责任、创造价值、工作贡献与个人
收入的正向强关联，建立固定薪资动态调整+上不封顶提成激励的联动机制，充分体现多劳多得、绩优
多得、能者多得的薪酬导向，全面调动销售人员的工作积极性和业绩创造力，特制定本办法。
二、 适用范围
本办法适用于公司所有直接销售人员，对应职级为 DS1 至 DS6。
三、 核心原则
价值导向：以岗位价值、业绩贡献、专业能力为核心核定薪资，匹配个人付出与收入回报；
动态调整：建立职级、薪资双向动态调整机制，能上能下、优升劣降，激发成长动力；
公平激励：区分市场开拓难度、任务目标层级，精准核定薪酬，兼顾公平与激励性；
多元叠加：固定薪资与提成激励并行，提成上不封顶，拓宽收入增长空间。
四、 固定薪资构成
销售岗位固定薪资=基准工资+任务工资+专业工资，三部分工资均按月核算发放。
(一) 基准工资
基准工资为固定薪资核心组成部分，根据销售人员岗位职级、年度任务目标及核心履职能力核定，体现
岗位基础价值与履职基本要求，具体标准如下表：
职级 基准工资（元） 年度任务目标 核心能力要求
DS1 3500 200W-299W 老客户履约率未达 100%，且有效客户开发能力较弱
DS2 4000 300W-399W 老客户履约率 100%，或具备有效 D 级客户开发能力
DS3 5000 400W-499W 老客户履约率 100%，或具备有效 C 级客户开发能力
DS4 6000 500W-599W 老客户履约率 100%，或具备有效 B 级客户开发能力
DS5 8000 600W-799W 老客户履约率 100%，或具备有效 A 级客户开发能力
DS6 10000 800W-1000W 开发 A 级客户并能主导渠道资源整合与大客户深度运营
核定说明：
1. 承接公司存量老客户的在岗人员，职级与年度任务目标原则上匹配对应；公司统一分配的 B 级及以
上客户资源，按 100 万元/个核算至个人年度任务目标；
2. 新入职销售人员，入职初期由直接上级联合 HRBP，根据面试评估的客户开发潜力、专业能力等维
度，共同核定初始职级及对应年度任务目标。

(二) 任务工资
任务工资与销售人员年度任务目标、所属市场开拓难度挂钩，体现按业绩付薪、按难度定薪的激励导向，
根据年度任务目标层级及市场类别核定，具体标准如下表（单位：元/月）：
年度任务目标 A 类市场 B 类市场 C 类市场 D 类市场
200W-299W 700 1000 1200 1500
300W-399W 1400 2000 2400 3000
400W-499W 2100 3000 3600 4500
500W-599W 2450 3500 4200 5250
600W-799W 2800 4000 4800 6000
800W-1000W 3150 4500 5400 6750
市场类别界定：
1. A 类市场：公司已布局成熟大客户或完善渠道，市场成熟度高，客户维护与业务成交难度相对较低；
2. B 类市场：市场发展成熟、客户合作关系稳定，为销售业务标准难度市场，作为任务工资核定基准；
3. C 类市场：行业竞争激烈、区域市场增长乏力，需投入更多资源开展市场突破与竞争，开拓难度高
于 B 类；
4. D 类市场：新开发空白市场、目标客户为纯散户群体，或处于竞品绝对垄断状态，市场开拓难度与
运营风险最高。
(三) 专业工资
专业工资为销售人员专业能力专项激励薪酬，体现按能力付薪导向，根据销售人员季度产品专业能力考
试成绩核定，用于激励销售人员持续深化产品知识、提升专业履职技能，具体标准如下：
季度专业能力考试分数 分数≥90 70≤分数<90 分数<70
月度专业工资（元） 2000 1000 0
核定与调整说明：专业工资实行季度动态调整，公司每季度统一组织产品专业能力标准化考试，考试结
果作为当季度专业工资核定唯一依据。
五、 职级动态调整机制
1. 公司每年组织一次销售岗位述职与人才盘点工作，以业绩评估（纵坐标）和潜力评估（横坐标）为
核心维度，形成九宫格评估结果，作为销售人员职级动态调整的核心依据。
2. 述职人才盘点结果为 A1、B1、A2 等级的销售人员，职级晋升一级，执行新职级对应的基准工资
标准；述职人才盘点结果为 C3 等级的销售人员，职级降低一级，执行新职级对应的基准工资标准；
其他评估结果人员，职级保持不变，继续执行当前职级薪酬标准。

六、 提成激励
适用本办法的销售人员，在享受固定薪资的同时，同步参与公司销售提成激励计划。提成激励实行上
不封顶原则，核心包含季度达成奖和定额客户开发奖两类，具体核定标准、发放条件及发放时间，按
公司发布的营销体系销售激励政策执行。
七、 管理要求
1. 对于季度累计任务达成率<70%的员工，HRBP 将在季度结束前一周发起 PIP（绩效改进计划）流
程，给予员工 3 个月绩效改进期；绩效改进期间员工不享受任务工资；
2. 员工当年度的薪资构成明细，在个人任务签署函中体现和告知；
八、 附则
1. 本制度自发布之日起执行，由公司人力资源部负责解释，此前与本办法不一致的薪酬相关规定，以
本办法为准。
