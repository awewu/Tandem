## 0. 一句话

**面向暖通设备品牌的营销中台**：把产品与技术事实变成 AI 可引用的品牌内容（GEO），
再用赋能工具让经销商专业成交。核心是品牌建设，从产品+GEO 破局，止于售前专业度。

**术语**：客户=经销商；终端业主=终端用户；前台=4 品牌站+经销商工作台；中台=Nexus。

**状态图例**：✅ 已建成可用 · 🟡 部分/进行中 · 🧊 冻结（超当期定位）· 📋 规划

## 3. L3 GEO 可见度引擎（核心破局点，已达学术 SOTA）

> **解决的根本问题**：AI 时代客户"想到你"的入口从搜索排名变为 **AI 推荐**。得知道 AI 提不提你、怎么让它提你、并证明有效。

| 功能 | 解决什么问题 | 用户利益 | 状态 | 前端 |
|---|---|---|---|---|
| 多引擎探测 | 不知 AI 怎么回答行业问题 | 12 引擎枚举，看 AI 回答里有没有我们 | ✅ | ✅ /growth/geo |
| **三层可见度**（cited/mentioned/none） | 把"被提及"当"被引用"，高估效果 | 只认真引用，**纠正虚假繁荣**（实测旧67%实为真引用0%） | ✅ | 🟡 API |
| 可见度度量 + 缺口识别 | 不知差在哪 | 定位"哪些问题 AI 不推荐我们" | ✅ | ✅ |
| **研究支撑策略库** | 内容生成靠拍脑袋 | 7 策略带论文实测增益（统计+41%/引用+30%/分块4.7×），默认注入高增益手法 | ✅ | ✅ GEO智能层 |
| **AI 内容生成** | 补内容慢、不专业 | 真 AI 生成，体现"依据 GB/T…"引用，成本落账 | ✅ | ✅ |
| **闭环实验（第7层）** | 无法证明"品牌建设有没有用" | before→lift→after，用 lift 数字证明内容有效 | ✅ | ✅ 实验面板 |
| **自进化（lift→权重）** | 好策略不会自动被优先 | 哪个策略 lift 高，下次自动优先用 | ✅ | ✅ 权重展示 |
| **受治理动作引擎**（Foundry式） | 人和 AI 各写各的、AI 乱写风险 | 人与 AI Agent 同一套治理闸；AI 代行需核准 | ✅ | ✅ GEO智能层 |
| 舆情雷达 | 不知外部怎么说我们 | 真实提及/情绪/风险汇总 | ✅（6端点） | ✅ /growth/sentiment |
| 文案 Copilot | 品牌文案产能不足 | 批量生成品牌一致文案，记所用策略 | ✅ | ✅ /growth/copywriter |
| 微信发布 | 内容分发到渠道难 | 审核→发布→记录闭环 | ✅（17端点） | 🟡 |
| 营销自动化/战役 ROI | 投放效果算不清 | 真实 CAC/ROI 看板（无数据如实空态） | 🟡 | ✅ /growth/automation |

**Tandem（搭子）= 集团员工中枢，不属于 Nexus。** Nexus 唯一依赖 = **AI 治理网关**
（不持模型 key，所有 AI 经 Tandem 的 TAF Router；文生图经 Tandem `/api/image-generation`）。
**不得向 Tandem 其他板块扩张。** Ontology 借鉴为"学思想、不共享代码、Nexus 本地实现"。
