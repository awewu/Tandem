# GTM 战略分析层设计（GEO 选题的上游）

> 起因：平台把 ~80% 精力放在"内容怎么写才被 AI 引用"（策略库/闭环/自进化），但**"该写哪些问题"没有方法论支撑**——上游为空，精密引擎打在没瞄准的靶上。
> 定位：本层是 **GEO 引擎的瞄准系统**。输出 = 排好优先级的选题（prompt），喂给已有的探测→生成→复投闭环。
> 关联：`COMPETITIVE-ANALYSIS.md` · `NEXUS-CAPABILITY-EVOLUTION.md` · `COMPETITIVE-INTELLIGENCE-DESIGN.md`。

## 0. 消费者行为前提（2026 实证，决定本层为何必须存在）
- 独立 AI 平台**已超越传统搜索**成为购买调研首要起点；AI 引荐流量 **176% CAGR**（L.E.K. 2,650 人 + 100 品牌流量）。
- **超 1/4 消费者到店/到站前已"心意已决"**——站内影响窗口被压缩。
- 42% 消费者近一月用过 AI 购物工具（NIQ）；41% 用 AI 研究产品（IBM IBV 18,000 人）；**72% 仍到店成交**。
- **结论：候选集经济（Shortlist Economy）**——AI 不替人决策，它替人**筛掉选项**。没进 AI 候选集 = 没有被评估资格。
- 对 HVAC（高决策成本 + 必须安装）：**AI 出候选 → 人（经销商）成交**，正是两支柱设计的现实依据。

## 1. 场景库 → prompt 簇 → 选题优先级（本层主干）
### 1.1 场景是 prompt 的唯一合法来源
消费者不问"变频参数"，问"北方老房没地暖怎么改""回南天太潮""婴儿房要多静音""电费能省多少""装了后悔的有哪些"。
**场景 = prompt。** 且**角色不同问法不同**（业主 / 装修公司 / 设计师 / 安装工），AI 给的答案也不同。

### 1.2 场景数据模型（五维）
`场景 = 品类 × 角色(audience) × 痛点(painPoint) × 房型(houseType) × 气候区(climateZone)`
- 场景骨架**品类级可复用**：换品类只换填充词表 → **新品类零人工获得初始 prompt 簇**（自循环冷启动的关键）。

### 1.3 prompt 簇派生（四来源）
1. **模板 × 词表**：`{品类}在{气候区}{房型}怎么选` / `{品类}{痛点}怎么办` —— 自动、零人工。
2. **同品类已有品牌的高价值 prompt 迁移**（同品类问题高度重合）。
3. **竞品占位反推**：竞品被引的问题 = 已验证有真实需求。
4. **PEST 事件雷达**注入时效题。

### 1.4 选题商业价值打分（决定做哪个）
`score = 意向强度 × 频次/热度 × 我方胜算`
- **意向强度**：信息型 < 对比型 < 决策/购买型（"X vs Y""怎么选""多少钱"权重高）。
- **频次/热度**：探测覆盖度、事件驱动时效。
- **我方胜算**：产品事实基座是否有支撑（无事实不生成，防幻觉）+ 当前是否已被引。
排序后进入闭环，避免"平均用力"。

## 2. PEST 雷达（选题的上游发动机 + 抢占时间窗）
每个 PEST 因子生成一簇真实提问：
- **P**：以旧换新补贴、能效新国标、双碳 → "补贴怎么领""新国标能省多少电费"
- **E**：电费敏感、装修预算 → "省电还是省安装费"
- **S**：北方老房无地暖、回南天、婴儿房静音、老龄化、养宠
- **T**：热泵路线、AI 家居 + **AI 引擎自身演变**（来源结构、llms.txt、AI Overview 覆盖率）

**GEO 独有价值**：政策/事件发布日 = 新问题涌现日；而 AI 引用来源**每月 40–60% 更替** → 窗口反复打开，先发布权威内容者被引。PEST 由此成为**可执行的抢占雷达**。

## 3. AI 视角 SWOT（把主观自评变成可测）
GEO 给经典框架的最大升级——**用探测数据客观生成**：
| 象限 | 定义（可测） | 数据源 |
|---|---|---|
| **S** | AI 主动提及我方、且我方被引的问题/优势点 | probe.weCited=true + aivs |
| **W** | **AI 说不出或说错我方的点**（真实弱点，非自我感觉）+ 幻觉 | weCited=false 且竞品被引；hallucination 标记 |
| **O** | 无人占位的内容缺口 | 可见度缺口检测（我方与竞品均弱） |
| **T** | 竞品在高价值 prompt / 高权重来源的占位 | competitorsCited 聚合 |
**这些数据平台已全部具备**，缺的只是组织成 SWOT 视图 → 本轮实现（A）。

## 4. 五力 + 第六力（决定"在哪个品类投 GEO"）
- **【新】第六力：AI 引擎作为新守门人**——决定候选集，规则不透明、月度剧烈波动、**Top 15 域名占 68% 引用份额**；**无法谈判，只能优化**。
- **买方议价能力↑↑**：一次提问即得对比表 → 信息不对称消失 → **产品事实必须经得起 AI 逐项对比**（证明事实基座是真护城河）。
- **新进入者壁垒被削平**：小品牌靠内容质量可绕过渠道进入答案（对我方既是机会也是威胁）。
- **替代品扩界**：AI 直接建议"改用多联机/热泵/新风" → 竞争从品牌间扩到**方案间**。
- **用法**：`AI 中介化程度 × 买方信息需求 × 我方事实优势` → **品类投入优先级**。

## 5. 与自循环（新增品牌/品类）的衔接
- 场景骨架品类级复用 + 同品类 prompt 迁移 + 竞品缺口反推 = **新品牌/品类冷启动自动获得选题**，闭环不空转。
- 对标 Yext：更根本的做法是把事实基座**实体图谱化**（产品↔内核↔场景↔品牌↔经销商），新增即挂接继承（后续设计）。

## 6. 实施顺序
- **A（本轮）**：AI 视角 SWOT 自动生成——数据已有，立即可测。
- **B（本轮）**：场景库数据模型 + prompt 簇派生 + 选题打分。
- **C（后续）**：PEST 事件雷达（需事件源）· 五力评估视图 · 实体图谱化。
