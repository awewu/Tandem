# 竞品情报(Insight)深化设计

> 起因：现状评估——`insight` 模块只是**手工台账**(扁平表 `{品类,竞品,维度,指标,值,来源}` + 5 个粗维度 + 唯一分析 `sovByCategory` 取最新值算占比 + 零自动采集)，**深度与广度均不足**。
> 目标：从"记录"升级为"分析系统"，并把已有但未打通的自动数据源接上。

## 0. 现状诚实盘点
- 维度仅 5：`product / price / channel / marketing / ai_sov`(颗粒粗)。
- 分析仅 1：`sovByCategory`(取每竞品最新 ai_sov 值算份额)——无趋势、无对比、无定位、无威胁评估。
- 采集：**全手工** `recordCompetitor`。
- **最大浪费**：GEO 探测已在记录竞品命中(`competitors`/`competitorsCited`)，却**未喂给 insight**。

## 1. 广度：5 扁平维度 → 8 维竞争力模型
| 维度 | 关键指标 |
|---|---|
| 产品力 | 参数级对比(能效/容量/噪音/保修)、产品线覆盖、**NPI 新品节奏** |
| 价格力 | 价位带分布、终端成交价、**促销强度/频次**、渠道价差 |
| 渠道力 | 经销商网络规模/城市覆盖、门店质量、线上旗舰店、返利政策 |
| 品牌力 | AI SoV、搜索/社媒声量、**口碑评分与情感** |
| 内容/GEO 力 | AI 引用份额、内容资产量、**站外来源结构占位**(Reddit/知乎/百科) |
| 服务力 | 安装售后网络、响应时效、投诉率 |
| 技术/专利 | 专利族、认证、技术路线 |
| 组织/扩张 | 招聘、开城、融资(领先指标) |

## 2. 深度：10 种分析方法(现状 0 → 目标)
1. **时序与动量**：每指标趋势 + 变化率 → 识别谁在加速(不只看最新值)。
2. **集中度**：SoV + HHI → 判断分散 vs 寡头格局。
3. **定位图**：价格×性能 / 价格×品牌力 → 找市场空白位。
4. **差距分析**：我方 vs 竞品逐维差距 + 加权综合得分。
5. **威胁评分**：动量 × 品类重叠度 × 资源 → 竞品危险度分级。
6. **事件检测与告警**：降价/新品/渠道政策变动自动触发(替代手工 signal)。
7. **话术对位(Messaging Diff)**：竞品主打话术 vs 我方 Messaging House → 可攻击点。
8. **赢丢单归因**：接 CRM——丢给谁、为什么(最硬情报，当前完全缺失)。
9. **AI 认知诊断**：AI 如何描述竞品 vs 我方(准确性/偏见/幻觉)。
10. **来源结构对比**：各引擎被引来源占位对比(接 GEO 站外洞察)。

## 3. 数据源：全手工 → 多源自动
| 源 | 可得性 |
|---|---|
| **GEO 探测竞品命中** | ✅ 现成、无外部依赖 → **优先打通** |
| 电商评价(京东/天猫) | 需抓取/接口 |
| 社区(知乎/小红书/B站) | 需抓取 |
| 官网参数/价格页 | 需抓取 |
| 招聘/专利/工商 | 公开数据源 |
| 媒体 PR | 需订阅 |

## 4. 实施顺序
- **A(先做，本机可完成)**：GEO 探测 → insight 自动喂 `ai_sov`。探测每次命中竞品即落一条时序数据点，`sovByCategory` 由"取最新值"改为**窗口内计数聚合**→ 竞品 AI 声量变成自动、持续、可比。
- **B**：时序/动量 + 集中度 + 差距分析(纯计算，基于已有数据即可)。
- **C**：事件检测告警 + 话术对位。
- **D**：赢丢单归因(接 CRM)、外部抓取源(需真环境/合规评估)。

## 5. 架构约束
- 跨模块反应走**事件(outbox)+ event-consumers**，不直接跨模块读表(守 ABC 边界)。
- 所有写入带 RLS 上下文 + 审计。
- 外部抓取需评估合规(robots/版权/反爬)——不在本设计内擅自开工。
