# 推荐产品配置与跳转

## What to build

让管理员为每个 Everhot 产品手工选择推荐产品、移除推荐和调整推荐顺序。公开详情接口返回真实推荐卡片数据，官网“您可能还关注”区域按照后台配置显示并跳转到对应产品详情。

推荐关系采用定向语义，产品 A 推荐产品 B 不应自动要求产品 B 推荐产品 A。

## Acceptance criteria

- [ ] 管理端能够搜索并选择其他 Everhot 产品作为推荐项。
- [ ] 当前产品不能推荐自己，同一目标不能被重复推荐。
- [ ] 管理端能够删除推荐项并调整推荐顺序。
- [ ] 公开详情接口仅返回仍处于上架状态的推荐目标。
- [ ] 推荐卡片包含名称、主图、标签、简介和稳定详情链接。
- [ ] 点击推荐卡片进入正确的产品详情页。
- [ ] 无有效推荐时不显示空推荐区域。
- [ ] 推荐创建、排序、下架过滤和官网跳转有自动化测试。
