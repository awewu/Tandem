# 规格参数与产品亮点编辑

## What to build

让管理员通过结构化表单维护产品规格参数和产品亮点，并让 Everhot 详情页运行时展示真实配置。编辑体验使用可增删、可排序的行项目，不要求管理员直接编辑 JSON。

## Acceptance criteria

- [ ] 管理端能够新增、编辑、删除和排序规格参数名称与值。
- [ ] 管理端能够新增、编辑、删除和排序产品亮点标题与说明。
- [ ] 空名称、空参数值和不完整亮点不能保存。
- [ ] 产品详情公开接口按管理端顺序返回规格参数和亮点。
- [ ] 官网顶部核心参数、规格表和亮点区域使用运行时真实数据。
- [ ] 没有规格或亮点时，对应页面区域不显示空容器。
- [ ] 保存、读取、排序和官网展示行为有自动化测试。
