# 产品主图与详情图片闭环

## What to build

为 Everhot 产品提供主图和多张详情图片管理。管理员能够在产品编辑界面上传、预览、更换、删除和排序图片；独立官网能够匿名读取并在产品卡片和详情页展示这些图片。

复用现有文件存储和产品素材引用能力，只补齐产品图片需要的角色、顺序和公开读取。PDF、规格书和技术资料上传明确不在范围内。

## Acceptance criteria

- [ ] 每个产品最多有一张主图，上传新主图时能够明确替换旧主图。
- [ ] 每个产品能够关联多张详情图片，并支持删除和排序。
- [ ] 管理端上传前显示文件名、类型、大小和图片预览。
- [ ] 产品列表卡片和详情页优先使用后台配置图片，缺图时保留现有降级展示。
- [ ] 独立官网能够读取已上架产品关联的公开图片，无需管理端登录。
- [ ] 未关联产品、已删除或不可公开的文件不能通过产品公开素材地址读取。
- [ ] 图片上传、关联、替换、删除、排序和官网展示有端到端测试。
