# 产品上下架、删除与官网排序

## What to build

在基础产品 CRUD 上补齐上架、下架、删除和展示顺序。管理员能够在产品列表中直接改变状态与排序，Everhot 官网只显示已上架产品，并按后台设置的顺序展示。

状态保持最小语义：`active` 表示上架，`inactive` 表示下架，`archived` 表示已删除。第一阶段不提供历史版本或恢复工作流。

## Acceptance criteria

- [ ] 管理端能够把产品设置为上架或下架。
- [ ] 管理端的删除操作将产品置为已删除状态，并从默认管理列表和官网隐藏。
- [ ] 管理端能够设置非负整数展示顺序。
- [ ] 首页精选、分类列表和公开产品接口按照展示顺序稳定返回产品。
- [ ] 下架或删除产品的公开详情返回未找到状态。
- [ ] 下架或删除产品不会出现在其他产品的公开推荐结果中。
- [ ] 状态与排序行为有管理 API、公开 API 和官网渲染测试。
